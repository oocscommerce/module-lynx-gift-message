# Lynx Gift Message

`oocscommerce/module-lynx-gift-message`

Gift messages from Magento_GiftMessage in the Lynx cart and on the order page.

## Features

- A message per item and one for the whole order, following Magento's gift message settings
- Disable it together with Magento_GiftMessage to drop gift messages

## Installation

Part of [Lynx](https://docs.oocscommerce.com/lynx/), installed with the metapackage:

```bash
composer require oocscommerce/magento2-lynx-community
```

See [Installation](https://docs.oocscommerce.com/lynx/developer/installation) for the full setup.
